# Privacy notice

WebGPU Video Upscaler processes supported video frames locally in the browser.
Video frames, playback state, and local performance measurements are not sent
to a remote server by the extension. The extension stores only the settings
needed to remember the user's local preferences through Chrome storage.

The extension requests storage and the YouTube content-script scope required
for its local overlay. It does not download or execute remote JavaScript or
WebAssembly. Model data, if added in a future release, must be versioned and
integrity-checked before use.

This notice describes the current package and does not replace platform or
browser privacy disclosures.
