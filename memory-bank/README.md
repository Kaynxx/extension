# Memory Bank

Bu klasör projenin oturumlar arası kalıcı hafızasıdır. Kodun ne yaptığını tekrar anlatmak yerine hedefi, kararları, güncel odağı ve doğrulanmış ilerlemeyi saklar.

## Dosyalar

- `projectbrief.md`: Değişmesi nadir proje hedefi ve kapsamı.
- `productContext.md`: Kullanıcı problemi, deneyim ve ürün ilkeleri.
- `systemPatterns.md`: Korunması gereken mimari desenler.
- `techContext.md`: Teknoloji seçimleri, platform kısıtları ve araç zinciri.
- `decisionLog.md`: Kalıcı mimari karar kayıtları.
- `activeContext.md`: Mevcut odak, yakın adımlar ve açık sorular.
- `progress.md`: Aşama bazlı doğrulanmış ilerleme.

Memory bank gerçeği temsil etmelidir. Planlanan ama tamamlanmayan işler tamamlanmış gibi yazılmaz.
